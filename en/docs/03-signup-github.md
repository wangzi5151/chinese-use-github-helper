# Register GitHub Account

## Registration Steps (Detailed with Screenshots)

### Step 1: Open Registration Page

1. Open browser (Chrome, Edge, or Firefox recommended)
2. Type **github.com** in the address bar and press Enter
3. Wait for the page to load
4. See the page shown below

```
┌─────────────────────────────────────────────────────────────┐
│  GitHub                          [Sign up]  [Sign in]      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│         Let's build from here                               │
│                                                             │
│    The world's leading AI-powered developer platform.       │
│                                                             │
│              [Sign up for GitHub]  [Start a free trial]     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

5. Click the **Sign up** button (blue button) in the top right corner of the page

### Step 2: Enter Email

1. Page jumps to registration form
2. Enter your email address in the **Email** input box
   - Recommend using Gmail, Outlook or other commonly used email
   - This email will be used for login and receiving notifications
3. After entering, click the **Continue** button

```
┌─────────────────────────────────────────────┐
│  Enter your email                           │
│  ┌─────────────────────────────────────┐    │
│  │ your-email@example.com              │    │
│  └─────────────────────────────────────┘    │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### Step 3: Set Password

1. Set password in the **Password** input box
   - Password must be at least 8 characters
   - Recommend including uppercase and lowercase letters, numbers, and special characters
   - Example: `MyPassword123!`
2. After entering, click the **Continue** button

```
┌─────────────────────────────────────────────┐
│  Create a password                          │
│  ┌─────────────────────────────────────┐    │
│  │ ••••••••••••                         │    │
│  └─────────────────────────────────────┘    │
│  Password must be at least 8 characters     │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### Step 4: Set Username

1. Set username in the **Username** input box
   - This is your unique identifier on GitHub
   - Can only use letters, numbers, and hyphens
   - Cannot start or end with hyphen
   - Example: `john-doe`, `js-developer`
2. System will automatically check if username is available
3. Green checkmark means available
4. Click the **Continue** button

```
┌─────────────────────────────────────────────┐
│  Enter a username                            │
│  ┌─────────────────────────────────────┐    │
│  │ john-doe                            │    │
│  └─────────────────────────────────────┘    │
│  ✓ john-doe is available                    │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### Step 5: Email Preference

1. Asks if you want to receive product update emails
2. Can choose **Receive product updates** or skip
3. Click the **Continue** button

### Step 6: Complete Verification

1. Page will show a verification code
2. Click the specified items in the image (e.g., "Please click all images containing traffic lights")
3. After completion, click the **Submit** button

```
┌─────────────────────────────────────────────┐
│  Verify your account                        │
│                                             │
│  [Image verification]                       │
│                                             │
│              [Submit]                       │
└─────────────────────────────────────────────┘
```

### Step 7: Verify Email

1. Check your email inbox
2. Find the email from GitHub
3. Enter the verification code in the email
4. Click **Verify** button

### Step 8: Choose Plan

1. Choose **Free** plan
2. Click **Continue** button

```
┌─────────────────────────────────────────────┐
│  Choose your plan                           │
│                                             │
│  ● Free                                     │
│    Unlimited public/private repos           │
│    2,000 automation minutes/month           │
│                                             │
│  ○ Pro ($4/month)                           │
│    Everything in Free, plus:                │
│    3,000 automation minutes/month           │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### Step 9: Complete Registration

1. Click **Skip personalization** to skip survey
2. Your GitHub account is now created!

## Post-Registration Setup

### Set Profile

1. Click avatar in top right corner
2. Select **Settings**
3. Click **Profile** in left menu
4. Fill in profile information:
   - **Name**: Your name
   - **Bio**: Brief introduction
   - **Location**: Your location
   - **Company**: Your company
   - **Social accounts**: Twitter, LinkedIn, etc.

### Upload Avatar

1. In profile settings page
2. Click **Upload new picture**
3. Select your avatar image
4. Click **Set new profile picture**

## Common Issues

### Q: Username already taken?

**Solution:**
- Try different variations
- Add numbers or underscores
- Use abbreviations

### Q: Email not received?

**Solution:**
- Check spam folder
- Wait a few minutes
- Click **Resend** button

### Q: Verification code expired?

**Solution:**
- Click **Resend** to get new code
- Enter new code

## Best Practices

1. **Use Real Information**: Helps others identify you
2. **Choose Good Username**: Easy to remember, professional
3. **Use Strong Password**: Include uppercase, lowercase, numbers, special characters
4. **Enable Two-Factor Authentication**: For security
5. **Set Profile**: Helps others understand you
