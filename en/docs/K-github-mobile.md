# GitHub Mobile Introduction

## What is GitHub Mobile?

GitHub Mobile is GitHub's official mobile application, allowing you to manage code, review PRs, handle Issues and more on your phone.

## Download and Install

| Platform | Download |
|----------|----------|
| iOS | App Store search "GitHub" |
| Android | Google Play search "GitHub" |
| Android (China) | Various app stores search "GitHub" |

## Main Features

### 1. Code Browsing

- Browse repository files
- View code changes
- Edit files
- Search code

### 2. Pull Requests

- View PR list
- Review code changes
- Add comments
- Merge PRs
- Request reviews

### 3. Issues

- View Issue list
- Create new Issues
- Add comments
- Add labels and assignees
- Close Issues

### 4. Notifications

- Real-time notifications
- View and manage notifications
- Mark as read

### 5. Discussions

- Participate in Discussions
- Answer questions
- Vote

### 6. Actions

- View workflow run status
- Re-run failed workflows
- View logs

## Quick Operations

### Notification Management

- **Swipe left**: Mark as read
- **Swipe right**: Ignore
- **Long press**: More options

### Issue and PR

- **Click**: View details
- **Long press**: Quick actions
- **Pull down refresh**: Get latest

## Settings and Configuration

### Notification Settings

1. Open GitHub Mobile
2. Click avatar in top left
3. Go to **Settings**
4. Configure **Notifications**

### Theme Settings

Supports dark mode and light mode:
1. **Settings** → **Appearance**
2. Select **Light**, **Dark** or **System**

### Multi-account Support

1. **Settings** → **Accounts**
2. Click **Add account**
3. Login to other account

## Security Features

### 1. Biometric Authentication

Supports Face ID and fingerprint unlock:
1. **Settings** → **Security**
2. Enable **Require Face ID/Touch ID**

### 2. Session Management

- Auto logout
- Remote logout
- Session history

### 3. Two-Factor Authentication

Supports TOTP and hardware keys.

## Best Practices

2. **Use Quick Operations**: Improve efficiency
3. **Configure Multi-account**: Separate work and personal accounts
4. **Enable Biometrics**: Protect account security
5. **Regularly Clean Notifications**: Keep tidy

## FAQ

### Q: Cannot login?
**A:** Check network connection, ensure correct credentials. If using 2FA, ensure correct verification code.

### Q: Notifications not timely?
**A:** Check phone notification permission settings, ensure GitHub Mobile has permission to send notifications.

### Q: Cannot edit files?
**A:** Some file types may not support mobile editing. Use desktop for complex edits.
