# Preface

## About This Book

This book is a complete GitHub guide for developers, from zero basics to advanced applications, covering Git version control, GitHub platform usage, team collaboration, DevOps practices, AI programming, enterprise applications, and more.

## Why Write This Book?

GitHub has become the world's largest code hosting platform, with over 100 million developers using it. For developers, mastering GitHub is not only a demonstration of technical ability, but also an essential skill for participating in the global open source community and enhancing career competitiveness.

However, GitHub learning resources have the following problems:

1. **Scattered Content**: Most tutorials only cover basic operations, lacking systematicity
2. **Outdated Updates**: Many contents are based on old versions, not including latest features
3. **Lacking Practice**: More theory, less practice
4. **Language Barrier**: Official documentation is in English, difficult for beginners

This book aims to solve these problems, providing readers with a systematic, comprehensive, and practical GitHub learning guide.

## Features of This Book

### 1. Systematic and Complete

From Git basics to GitHub advanced features, from personal development to enterprise collaboration, this book covers all aspects of the GitHub ecosystem.

### 2. Rich Illustrations

Every operation step is accompanied by detailed graphical interface explanations, making it easy for zero-basis beginners to get started.

### 3. Practice-Oriented

This book contains 20+ hands-on exercises, with practical tasks accompanying each chapter, helping readers master knowledge through practice.

### 4. China Optimization

Specially designed for developers in China, providing domestic acceleration solutions, mirror configurations, localized tool recommendations, and more.

### 5. Continuous Updates

This book will be continuously updated as GitHub updates, ensuring readers always learn the latest features.

## Who Should Read This Book?

- **Programming Beginners**: Beginners who want to learn Git and GitHub
- **Students**: Students who want to improve technical skills and prepare for job hunting
- **New Professionals**: Developers who just started using GitHub at work
- **Transitioning Developers**: Developers transitioning from other platforms to GitHub
- **Technical Leaders**: Managers who want to establish team GitHub standards
- **Open Source Enthusiasts**: Contributors who want to participate in open source communities

## How to Use This Book?

### Zero-Basis Readers

It is recommended to read Parts 1 to 3 in order, completing all exercises.

### Readers with Basics

You can directly jump to chapters of interest, looking up the content you need.

### As a Reference Manual

This book can also be used as a GitHub usage manual, looking up relevant chapters when encountering problems.

## Book Structure

This book is divided into ten parts:

1. **Getting Started**: Register accounts, install tools, configure environment
2. **Git Core Commands**: Basic knowledge of version control
3. **GitHub Core Features**: Repositories, Issues, PRs, Actions
4. **Collaboration and Advanced**: Team collaboration, workflows, code review
5. **GitHub Ecosystem**: Copilot, Packages, Pages, Projects
6. **Security and DevOps**: Security practices, CI/CD, automation
7. **Enterprise and Business**: Enterprise governance, team standards, commercial operations
8. **China Developer Zone**: Acceleration solutions, domestic platforms, FAQs
9. **Practical Cases**: Complete project practice
10. **Hands-on Exercises**: 20+ hands-on exercises
