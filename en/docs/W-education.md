# GitHub Education Resources

## GitHub Student Developer Pack

### What is Student Developer Pack?

GitHub provides free development tools and resource packages for students, including:
- GitHub Pro account
- Various development tools discounted or free
- Cloud service credits

### Application Requirements

- Have .edu email or student proof
- At least 13 years old
- Currently enrolled student

### Application Steps

1. Visit https://education.github.com/pack
2. Click **Get your pack**
3. Fill in school information
4. Upload student proof
5. Wait for review

### Included Resources

| Tool | Value | Description |
|------|-------|-------------|
| GitHub Pro | $4/month | Enhanced features |
| GitHub Copilot | $10/month | AI programming assistant |
| DigitalOcean | $200 | Cloud servers |
| JetBrains | Free | IDE tools |
| Namecheap | Free domain | .me domain |
| MongoDB Atlas | $200 | Database |
| Heroku | $5/month | Cloud platform |
| .NET | Free | Microsoft development tools |

## GitHub Campus Experts

### What are Campus Experts?

GitHub trains student leaders to help them build tech communities on campus.

### Application Requirements

- 18 years or older
- Currently enrolled student
- Have leadership experience
- Interested in open source

### Application Process

1. Visit https://education.github.com/community
2. Submit application
3. Attend interview
4. Complete training

## Learning Path

### Beginner Path

```
1. Learn Git Basics
   └── Git official tutorial
   └── This repository documentation

2. Register GitHub Account
   └── Complete profile
   └── Create first repository

3. Learn Programming Language
   └── Choose a language
   └── Complete basic course

4. Complete Practice Exercises
   └── Exercises in this repository
   └── Personal projects
```

### Intermediate Path

```
1. Deep Dive into Git
   └── Advanced commands
   └── Workflows

2. Participate in Open Source
   └── Fork projects
   └── Submit PRs

3. Learn CI/CD
   └── GitHub Actions
   └── Automated deployment

4. Build Personal Brand
   └── Maintain GitHub profile
   └── Write tech blog
```

### Expert Path

```
1. Contribute to Large Projects
   └── Become maintainer
   └── Review PRs

2. Create Own Projects
   └── Solve real problems
   └── Build community

3. Share Knowledge
   └── Write tutorials
   └── Give talks

4. Career Development
   └── Technical interviews
   └── Open source work
```
