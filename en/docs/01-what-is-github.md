# What is GitHub?

## GitHub Introduction

GitHub is the world's largest code hosting platform, built on the Git version control system. It is not just a code repository, but a complete developer collaboration platform.

## What Can GitHub Do?

| Feature | Description |
|---------|-------------|
| **Code Hosting** | Securely store your code in the cloud |
| **Version Control** | Track every code change, revert anytime |
| **Collaborative Development** | Multiple people work on the same project simultaneously |
| **Code Review** | Quality control through Pull Requests |
| **Project Management** | Manage development progress with Issues, Projects |
| **Automation** | Implement CI/CD through GitHub Actions |
| **Open Source Community** | Participate in or launch open source projects |

## Relationship Between Git and GitHub

```
Git (Version Control Tool)  ≠  GitHub (Hosting Platform)
    ↓                              ↓
  Local Use                    Cloud Service
  Command Line Operations      Web Interface + API
  Manage Code History          Collaboration + Social Features
```

Simply put:
- **Git** is software installed on your computer for managing code versions
- **GitHub** is a website that uses Git as its underlying tool, providing collaboration and social features

## Why Choose GitHub?

1. **Industry Standard**: Over 100 million developers use it
2. **Free Plan**: Personal repositories are completely free
3. **Rich Ecosystem**: Numerous integrations and plugins
4. **Learning Resources**: Massive open source projects to learn from
5. **Resume Booster**: An active GitHub profile proves technical ability

## Hands-on Exercise

### Exercise: Register Your First GitHub Account

**Step 1: Open Registration Page**
1. Open browser (Chrome or Edge recommended)
2. Type **github.com** in the address bar and press Enter
3. Click the **Sign up** button in the top right corner

**Step 2: Fill in Registration Information**
1. Enter your email address (recommend using a frequently used email)
2. Set password (at least 8 characters, including letters and numbers)
3. Set username (this is your unique identifier on GitHub)
4. Click **Continue**

**Step 3: Verify Account**
1. Check your email for the verification code from GitHub
2. Enter the verification code
3. Complete human verification

**Step 4: Choose Free Plan**
1. Select the **Free** plan
2. Complete survey (optional, can skip)
3. Click **Submit**

**Step 5: Explore the Interface**
1. After signing in, click the **+** in the top right corner
2. Select **New repository**
3. Observe the repository creation interface
