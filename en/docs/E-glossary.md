# Git and GitHub Glossary

## Basic Concepts

| Term | Description |
|------|-------------|
| Repository (Repo) | Project's storage space, contains all files and history |
| Clone | Copy remote repository to local |
| Commit | Save changes to local repository |
| Branch | Independent development line |
| Merge | Combine changes from two branches |
| Stage | Mark changes as ready to commit |
| Remote | Repository copy hosted on server |
| Working Directory | Directory where you're editing files |
| Index | Another name for staging area |

## Git Operations

| Term | Description |
|------|-------------|
| Rebase | Replay current branch commits onto target branch |
| Reset | Undo commit or staging |
| Revert | Create new commit to undo previous changes |
| Checkout | Switch branch or restore file |
| Stash | Temporarily save uncommitted changes |
| Cherry-pick | Pick specific commit from another branch |
| Squash | Combine multiple commits into one |

## GitHub Features

| Term | Description |
|------|-------------|
| Pull Request (PR) | Request to merge code with review process |
| Issue | Used to track bugs, feature requests, etc. |
| Fork | Copy someone's repository to your account |
| Code Review | Review code quality and security |
| Actions | GitHub's CI/CD automation platform |
| Pages | Static website hosting service |
| Projects | Kanban-style project management tool |
| Discussions | Community discussion forum |
| Packages | Package management service |
| Release | Software version release |
| Tag | Mark specific commit (usually for versions) |

## Security Related

| Term | Description |
|------|-------------|
| SSH | Secure Shell, secure remote connection protocol |
| Key | Encrypted credential for authentication |
| Token | String used for API authentication |
| 2FA | Two-Factor Authentication |
| Dependencies | Other packages that project relies on |
| Vulnerability | Security weakness |
| CODEOWNERS | File defining code review responsibilities |

## Workflow Terms

| Term | Description |
|------|-------------|
| Trunk-Based Development | Everyone commits directly to main branch |
| Feature Flags | Control feature enable/disable at runtime |
| CI (Continuous Integration) | Automated build and testing |
| CD (Continuous Deployment) | Automated deployment to production |
| Pipeline | CI/CD workflow |
| Workflow | GitHub Actions automation configuration |
| Runner | Server that executes GitHub Actions |

## Version Control

| Term | Description |
|------|-------------|
| Commit Message | Text describing commit content |
| Hash | Commit's unique identifier (SHA-1) |
| HEAD | Pointer to current branch's latest commit |
| History | Ordered list of commits |
| Conflict | Differences that can't be auto-resolved during merge |
| Base | Branch used for comparison or merge |
| Upstream | Original repository (relative to Fork) |
| Downstream | Forked repository |

## Common Abbreviations

| Abbreviation | Full Form | Description |
|--------------|-----------|-------------|
| PR | Pull Request | Code merge request |
| MR | Merge Request | Merge request (GitLab usage) |
| CI | Continuous Integration | Automated build and test |
| CD | Continuous Deployment | Automated deployment |
| LGTM | Looks Good To Me | Review approved |
| WIP | Work In Progress | In progress |
| TBD | To Be Determined | Pending decision |
| N/A | Not Applicable | Not applicable |
